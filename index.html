Jackbox Player

Paste a stream URL in the bar below, or add it as a query param:

?code=ABCD&stream=https://twitch.tv/channel

Supported streams

  • YouTube — youtube.com/watch, youtu.be, youtube.com/live
  • Twitch — twitch.tv/channel
  • HLS / Owncast — any .m3u8 URL
  • Video — .mp4, .webm, .ogg

Controls

  • ⇄ Swap H — swap stream and game left/right
  • ⇅ Swap V — swap stream and game top/bottom (portrait)
  • ⟳ Reload — reload stream only, game stays alive
  • ☀️ / 🌙 — toggle light/dark theme
  • Swipe left/right — swap panes on touch
